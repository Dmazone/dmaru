D.Maru 디마루

실시간 다국어 번역 & 어학 학습 앱 — 133개 언어 지원

D.Maru란?

D.Maru(디마루)는 외국인과의 실시간 대화와 어학 학습을 동시에 지원하는 모바일 웹 앱입니다. 한국어, 영어, 일본어, 스페인어, 태국어, 광동어 등 133개 언어를 즉시 번역하며, 타이핑하는 순간 번역 결과가 실시간으로 나타납니다.

주요 기능

  • 실시간 3단 번역 — 입력과 동시에 최대 2개 언어로 즉시 번역. 500ms 이내 결과 표시.
  • 번역 채팅방 — 서로 다른 언어를 쓰는 사람들과 실시간으로 채팅. 메시지가 자동 번역되어 표시됩니다.
  • 외국어 학습 — 매일 10분 학습 루틴, 연속 학습 스트릭, TTS 네이티브 발음 청취.
  • 음성 입력 — 말하면 즉시 번역. 여행 중 외국인과 대화할 때 유용합니다.
  • 6자리 초대 코드 — 채팅방을 만들고 코드 공유만으로 누구든 초대 가능.

지원 언어

Google Cloud Translation API 기반으로 한국어, 영어, 일본어, 중국어(간체·번체·광동어), 스페인어, 프랑스어, 독일어, 아랍어, 힌디어, 태국어, 베트남어, 인도네시아어 등 전 세계 133개 언어를 지원합니다. 언어 장벽 없이 누구와도 대화하세요.

활용 예시

  • 해외여행 중 현지인과 즉석 대화
  • 외국인 친구나 동료와 메시지 교환
  • 일본어, 스페인어 등 외국어 독학 및 회화 연습
  • 다국적 팀의 실시간 업무 커뮤니케이션
  • 언어 교환 파트너와 채팅방에서 연습
